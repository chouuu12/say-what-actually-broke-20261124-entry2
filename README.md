One line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh on the way.

> Your file is safe. The folder you saved it in is not — someone renamed it mid-save. Search for the filename; it didn't go far.

`main.ts` (Node 22, stdlib only) reads `line.txt`, validates it (single line, 1–200 characters, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
